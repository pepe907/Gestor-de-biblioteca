# Gestor Biblioteca — Spring Boot

##  Información

Proyecto desarrollado con el objetivo de fortalecer mis conocimientos en el desarrollo de **APIs REST con Spring Boot**.

En este proyecto estoy trabajando con:

*  Java
*  Spring Boot
*  PostgreSQL
*  Spring Data JPA
* ️ Ingeniería inversa
*  APIs REST

El proyecto consiste en desarrollar un sistema básico para la gestión de una biblioteca, aplicando conceptos de **programación orientada a objetos, persistencia de datos, relaciones entre entidades y desarrollo de APIs**.

##  Objetivo

Fortalecer mis habilidades en el desarrollo backend mediante la creación de una API para gestionar los diferentes recursos de una biblioteca.

##  Tecnologías

| Tecnología      | Uso                     |
| --------------- | ----------------------- |
| Java            | Lenguaje principal      |
| Spring Boot     | Desarrollo del backend  |
| Spring Data JPA | Persistencia y ORM      |
| PostgreSQL      | Base de datos           |
| Maven           | Gestión de dependencias |
| Git / GitHub    | Control de versiones    |

## Funcionalidades

Actualmente el proyecto se encuentra en desarrollo.

Entre las funcionalidades planeadas se encuentran:

* Gestión de libros
* Gestión de autores
* Gestión de categorías
* Gestión de usuarios
* Préstamos de libros
* Devolución de libros
* Consultas mediante API REST

##  Base de datos

El proyecto utiliza **PostgreSQL** como sistema gestor de base de datos y **JPA/Hibernate** para realizar el mapeo entre las entidades Java y las tablas de la base de datos.

##  Estado del proyecto

**En desarrollo 🚀**

El proyecto se irá ampliando progresivamente a medida que avance en el aprendizaje de Spring Boot y el desarrollo de APIs REST.
